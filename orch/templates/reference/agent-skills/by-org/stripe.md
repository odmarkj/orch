# Stripe Agent Skills

Stripe publishes 2 official skills: one for integration best practices and one for SDK/API version upgrades. These are maintained by the Stripe engineering team and encode the patterns that Stripe's own developer advocates recommend.

The best practices skill is especially useful when building payment flows, subscription management, or checkout integrations. The upgrade skill helps migrate between Stripe SDK versions and API versions, which change frequently.

---

- **stripe/stripe-best-practices** -- Best practices for building Stripe integrations. Covers payment flows, webhook handling, error management, idempotency, and security patterns.
  Source: https://officialskills.sh/stripe/skills/stripe-best-practices

- **stripe/upgrade-stripe** -- Upgrade Stripe SDK and API versions. Handles breaking changes, deprecation warnings, and migration steps between versions.
  Source: https://officialskills.sh/stripe/skills/upgrade-stripe
