# Tailwind CSS Agent Skills

There is no official Tailwind CSS skill in the awesome-agent-skills repository. However, Tailwind is referenced extensively across other skills. Vercel's web design guidelines and React best practices skills include Tailwind patterns. Anthropic's web-artifacts-builder uses React and Tailwind. Expo publishes a dedicated Tailwind setup skill for React Native via NativeWind.

For Tailwind-adjacent frontend styling guidance, the best sources are the Vercel design skills, the GSAP animation skills (for motion), and the community UI skills. The Google Labs Stitch skills also use Tailwind via shadcn/ui components.

---
