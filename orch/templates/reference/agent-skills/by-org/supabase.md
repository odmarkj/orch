# Supabase Agent Skills

Supabase publishes 1 official skill focused on PostgreSQL best practices for the Supabase platform. While limited in number, this skill encodes the patterns recommended by the Supabase team for schema design, queries, RLS policies, and database optimization on their managed Postgres platform.

For related database skills, Neon publishes serverless Postgres skills, ClickHouse covers analytics, MongoDB covers document databases, and DuckDB covers local analytical queries. The community also has a read-only PostgreSQL query skill.

---

## Official Supabase
- **supabase/postgres-best-practices** -- PostgreSQL best practices for Supabase including schema design, Row Level Security, query optimization, and migration patterns
  Source: https://officialskills.sh/supabase/skills/postgres-best-practices
