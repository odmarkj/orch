# Vercel Agent Skills

Vercel's engineering team publishes 7 official skills covering React best practices, Next.js patterns, component composition, caching strategies, web design guidelines, React Native, and Next.js upgrades. These are authoritative guides from the team that builds and maintains Next.js and the Vercel platform.

The Next.js skills are particularly valuable for caching (a historically confusing area) and upgrade paths. The React best practices skill covers modern patterns including Server Components. The composition patterns skill focuses on reusable component architecture.
