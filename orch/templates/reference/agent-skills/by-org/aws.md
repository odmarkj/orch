# AWS Agent Skills

AWS does not have an official first-party skill set in the awesome-agent-skills repository. However, Microsoft publishes extensive Azure SDK skills (133 skills across 6 languages), and there is a notable community AWS skill. Additionally, HashiCorp's Terraform skills cover multi-cloud infrastructure including AWS.

For AWS-specific agent guidance, the community skill by zxkane is the primary resource. For infrastructure-as-code on AWS, the HashiCorp Terraform skills (11 skills) and the community Terraform skill by antonbabenko are the best options.
