# Frontend, UI & Styling Agent Skills

Frontend skills span React/Next.js (Vercel), React Native (CallStack, Expo, Vercel), design-to-code (Figma, Google Labs Stitch), animation (GSAP/GreenSock), web design (Vercel, Addy Osmani), and mobile native (Expo, MiniMax). The strongest collections come from Vercel (7 skills covering React, Next.js, and design), GSAP (8 animation skills), Expo (12 mobile skills), and Figma (7 design-to-code skills).

Key patterns: Vercel's React and Next.js skills are authoritative for those frameworks. GSAP provides complete animation coverage from core API to ScrollTrigger to React integration. Expo covers the full mobile lifecycle including Tailwind setup, native UI, and deployment. Figma skills bridge design tools to production code.
