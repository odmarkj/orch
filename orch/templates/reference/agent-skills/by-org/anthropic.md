# Anthropic Official Agent Skills

Anthropic publishes 16 official skills for Claude Code covering document creation (Word, PowerPoint, Excel, PDF), visual design (generative art, canvas design, frontend design), web artifact building, MCP server creation, and web app testing. These are first-party skills maintained by the Claude team and serve as reference implementations for the skill format.

The document skills are particularly useful for generating reports, presentations, and spreadsheets directly from Claude sessions. The design skills enable visual output without leaving the CLI. The MCP builder and skill creator are meta-skills for extending Claude's own capabilities.
