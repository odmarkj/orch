# Google Agent Skills

Google publishes agent skills across three divisions: Google Gemini (API development), Google Labs/Stitch (design-to-code workflows), and Google Workspace CLI (productivity suite management). The Gemini skills cover building apps with the Gemini API including live streaming and interactions. The Stitch skills from Google Labs focus on converting designs into React/shadcn components. The Workspace CLI skills provide comprehensive management of Google's productivity tools through the `gws` CLI.

The Workspace CLI collection is notably large (17 skills) and covers every major Google service. The Gemini API skills differentiate between standard API, Vertex AI, Live API (bidirectional streaming), and Interactions API. Addy Osmani (Chrome team) also publishes web quality skills covering Lighthouse-style audits.

---

## Google Gemini -- API Development
- **google-gemini/gemini-api-dev** -- Best practices for Gemini-powered apps using the Gemini API
- **google-gemini/vertex-ai-api-dev** -- Gemini on Google Cloud Vertex AI using the Gen AI SDK
- **google-gemini/gemini-live-api-dev** -- Real-time bidirectional streaming with Gemini Live API
- **google-gemini/gemini-interactions-api** -- Text, chat, streaming, and image generation
  Source: https://officialskills.sh/google-gemini/skills/
