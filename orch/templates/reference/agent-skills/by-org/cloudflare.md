# Cloudflare Agent Skills

Cloudflare publishes 6 official skills covering their Workers platform, Durable Objects, AI agent SDK, MCP server building, web performance auditing, and the Wrangler CLI. These skills encode the patterns for building on Cloudflare's edge computing platform.

The wrangler skill is the most broadly useful -- it covers deploying and managing Workers, KV, R2, D1, Vectorize, Queues, and Workflows. The agents-sdk and building-ai-agent skills are important for anyone building stateful AI applications on Cloudflare. The Durable Objects skill covers stateful coordination with RPC, SQLite, and WebSockets.

---

- **cloudflare/wrangler** -- Deploy and manage Workers, KV, R2, D1, Vectorize, Queues, Workflows via Wrangler CLI
  Source: https://officialskills.sh/cloudflare/skills/wrangler

- **cloudflare/agents-sdk** -- Build stateful AI agents with scheduling, RPC, and MCP servers on Cloudflare
  Source: https://officialskills.sh/cloudflare/skills/agents-sdk

- **cloudflare/building-ai-agent-on-cloudflare** -- Build AI agents with state management and WebSockets on Cloudflare Workers
  Source: https://officialskills.sh/cloudflare/skills/building-ai-agent-on-cloudflare

- **cloudflare/building-mcp-server-on-cloudflare** -- Build remote MCP servers with tools and OAuth on Cloudflare
  Source: https://officialskills.sh/cloudflare/skills/building-mcp-server-on-cloudflare

- **cloudflare/durable-objects** -- Stateful coordination with RPC, SQLite, and WebSockets
  Source: https://officialskills.sh/cloudflare/skills/durable-objects

- **cloudflare/web-perf** -- Audit Core Web Vitals and render-blocking resources
  Source: https://officialskills.sh/cloudflare/skills/web-perf
